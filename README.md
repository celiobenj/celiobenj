### Sobre Mim

Sou estudante de Engenharia de Computação na **Universidade do Estado do Amazonas (UEA)** e líder de Sistemas Embarcados no [**GEAR (Grupo de Estudos Aplicados à Robótica)**](https://github.com/GEAR-EST). Meu foco principal é o desenvolvimento de hardware e firmware para robótica de competição, automação e IoT.

Atualmente, trabalho no desenvolvimento de arquiteturas de alta performance para robô Seguidor de Linha.

### Principais Projetos

| Projeto | Descrição Técnica | Stack |
| :---: | :--- | :--- |
| [**Robô Seguidor de Linha Pro 2025**<br>*(GEAR - UEA)*](https://github.com/GEAR-projects/SEGUIDOR_PRO_2025) | Firmware de competição para ESP32 utilizando FreeRTOS para controle multitarefa (Dual Core).
